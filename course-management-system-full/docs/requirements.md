# Requirements

## Functional

1. Home page with project introduction and navigation.
2. Login page with email/username and password.
3. Registration page with student details.
4. Dashboard with student information.
5. Course catalogue.
6. Enrolment/progress information.
7. Notifications.
8. Client-side form validation.
9. Dynamic login/logout navigation.
10. Protected dashboard/course routes.
11. Course GET/POST/PUT/DELETE operations.
12. Loading and error states.
13. Centralized application state.

## Non-functional

- Responsive desktop/tablet/mobile UI.
- No intentional horizontal overflow at common viewport widths.
- Reusable React components.
- Separated API and validation modules.
- Clear project documentation.
- Distinct visual identity.
