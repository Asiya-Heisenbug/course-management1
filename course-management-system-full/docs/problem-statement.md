# Problem Statement

Course Command is designed as a student learning management application.

The system provides a central interface where students can create an account, authenticate, view their profile, discover courses, see enrolment/progress information and receive notifications.

A course-management workflow is also included so course records can be created, viewed, edited and deleted through a mock REST API.

The project demonstrates the progression from frontend structure and styling to JavaScript validation, modular code, React components, routing, API integration and centralized state management.
